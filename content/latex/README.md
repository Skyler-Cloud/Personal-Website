# LaTeX projects

Upload a standalone .tex or Overleaf source ZIP. Create an article in writing/ with `latex: project.zip`, optional `latexMain: main.tex`, and optionally `latexPdf: true` plus `latexEngine: pdflatex` (or xelatex/lualatex). The document is converted to native HTML and MathML inside the article; the PDF is optional. Unsupported macros/packages may need adjustment. Only trusted, public author-owned sources; no live Overleaf sync.
